# OptimalPrint

OptimalPrint is a free web app that instantly generates optimized 3D print settings based on your printer, filament, and model.

The platform helps makers improve print quality, reduce failed prints, and save time by generating accurate slicer parameters and intelligent printing recommendations.

---

## Features

* Optimized 3D print settings generation
* Printer and filament-based tuning
* Failure risk analysis
* Troubleshooting recommendations
* Print cost estimation
* Expert printing tips
* Fast and simple web interface

---

## How It Works

1. Select your printer
2. Choose filament type
3. Enter model details
4. Generate optimized print settings instantly

OptimalPrint automatically analyzes the inputs and recommends settings designed to improve print success rates and overall quality.

---

## Technologies Used

* Python
* Flask
* HTML/CSS
* JavaScript

---

## Goal

OptimalPrint was built to make 3D printing easier for beginners and more efficient for experienced makers by reducing trial-and-error tuning.

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Muflih-7/Optimal-Print.git
```

Open the project folder:

```bash
cd Optimal-Print
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
python app.py
```
